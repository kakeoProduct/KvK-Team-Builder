# 自己点検リスト

指摘へ対応した作成者（主エージェント）が、再レビューを依頼する前に1項目ずつ確かめる。
確かめた結果は、レビュー結果の「振り返り」の節に書く。項目は、再レビューで見つかった指摘の
原因から作る。追加と見直しの手順は`SKILL.md`の「振り返る」に従う（ADR 0024）。各行の出所は、
その項目を提案したPull Requestの番号（まだなければbranch名）で示す。C1、C10、C12、C13の例は、#43で追加する
`docs/requirements/team-building/`の用語（隊、序盤、延長境界時刻、休止、出撃開始時刻）を、C14、C15の例は
同じ文書のFRM-090の用語（判定に使う編成、指定）を使う。この文書は、
#43がmergeされるまでは#43のbranchにある。
