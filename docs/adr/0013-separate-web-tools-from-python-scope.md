# ADR 0013: ブラウザ用補助ツールをPython処理の対象外とする

- 状態: 提案中（一部をADR 0021で置き換え）
- 日付: 2026-10-15
- 置き換え: HTMLの計算をPythonへ移植しない点と、CIへNode.jsを追加しない点はADR 0021で置き換えた。
  `web/`をPythonの品質ゲートの対象外とする扱いは、置き換えが済むまで維持する

## 背景

`web/`には、攻城タイムライン計算、占領判定、同着カウントアップ／カウントダウン、周期ウェーブ
タイマーの単体HTMLツールがある。これらは行軍秒数、集結時間、占領時間、周期を秒単位で扱う
KvK当日の補助計算であり、参加時間に応じたA〜K編成を作るPythonの処理と一致する部分がない。
一方、`web/work/inject_sidebar.py`がRuffの対象に含まれ、品質ゲートを失敗させていた。

## 判断

- `web/`の計算ロジックは各HTMLを正本とし、Pythonのドメインやアダプターへ移植しない
- `web/`は境界づけられたコンテキスト「KvKチーム編成」の外にある独立ツールとして扱い、
  `docs/architecture.md`の将来のWeb UIとも区別する
- Ruffの`extend-exclude`へ`web`を追加し、Ruff、mypy、pytestの品質ゲートの対象外とする
- READMEとアーキテクチャ文書へ境界を明記する

## 代替案

### HTMLの計算をPythonのドメインへ移植する

Botや自動化から利用できるが、JSとPythonへ同じ計算が二重に存在し、整合を保つには
CIへNode.jsを追加する必要がある。現時点で利用者がいないため採用しない。

### `web/work/inject_sidebar.py`だけを整形して品質ゲートへ残す

当面のCIは通るが、HTML側のScriptへPythonの開発規約を適用する根拠がなく、HTMLツールの
作業がPythonの品質ゲートに縛られるため採用しない。

## 影響

`web/`の変更はPythonの品質ゲートで検証されない。HTMLツールの正しさはブラウザでの動作確認で
担保する。Python側へ移植または連携する要求が生じた場合は、本ADRを置き換えるADRで用途、
用語、二重実装の整合方法を決める。
