# アーキテクチャ判断記録

ADRは、後から変更理由を追跡する必要がある重要な技術・プロダクト判断を記録します。

## 運用

1. `0000-template.md`をコピーし、4桁の連番と短い英語名を付ける
2. 状態を「提案中」として変更案と同じPull Requestへ含める
3. レビュー後に「採用」または「却下」へ更新する
4. 採用済みADRを直接書き換えず、新しいADRから置き換え対象を参照する。例外は、ADR 0026で伏せた語と、
   それを含む識別子の表記の書き換えと、書き換えたことを示す注記だけとする
