# 要件定義: KvK占領戦 勝利判定ツール

| 項目 | 内容 |
|---|---|
| 対象ファイル | `web/KvK占領判定.html` |
| 表示名 | 「KvK占領戦 勝利判定ツール」 |
| 状態 | 稼働中 |
| 要件ID接頭辞 | `OCC` |
| 現行仕様の確認日 | 2026-10-17（コードの読解による。ブラウザでの動作確認は未実施） |

## 1. 目的と利用場面

KvK占領戦で、各同盟の累計占領時間から、勝利が確定するまでに必要な残りの占領時間を分単位で
示す。試合時間内の累計占領時間が最も長い同盟が勝つことを前提とする。

## 2. 用語

| 用語 | 意味 |
|---|---|
| 試合時間 | 占領戦の全体時間 |
| 合計経過 | 全同盟の占領時間の合計 |
| 残り時間 | `試合時間 - 合計経過` |
| 首位 | 占領時間が最大の同盟。同率の場合は全員を首位とする |
| 比較相手 | 首位の同盟には2番目に長い同盟、それ以外の同盟には首位の同盟 |
| 確定まで | 残り時間をすべて比較相手が占領しても上回るために、自分が追加で必要な占領時間 |

## 3. 機能要件

### 3.1 入力

| ID | 要件 |
|---|---|
| OCC-001 | 「試合時間」を時間単位で入力できる。既定値は5、0.5刻みで小数を入力できる |
| OCC-002 | 5つの同盟について、同盟名と占領時間（時、分、秒）を入力できる。行の追加と削除はできない |
| OCC-003 | 初回表示時は「こぐま」2:17:12、「相手メイン」0:37:34、「999」0:15:03、「相手ゴースト」0:10:16、「その他」0:00:00を表示する |
| OCC-004 | 空欄や数値でない値は0として扱う |

### 3.2 計算規則

| ID | 要件 |
|---|---|
| OCC-010 | 入力のたびに即時に再計算する |
| OCC-011 | 各同盟の合計秒を`時 × 3600 + 分 × 60 + 秒`とする |
| OCC-012 | 残り時間を`試合時間 × 3600 - 全同盟の合計秒の和`とする |
| OCC-013 | 必要秒数を`max(0, floor((比較相手の合計秒 + max(0, 残り時間) - 自分の合計秒) / 2) + 1)`とする。自分がx秒を取り、残りを比較相手がすべて取っても、自分が厳密に上回る最小のxである |
| OCC-014 | 必要秒数が0の場合は「確定！」、それ以外は必要秒数を分へ切り上げて「{分}分」と表示する |

### 3.3 表示

| ID | 要件 |
|---|---|
| OCC-020 | 表の列は「同盟」「時(H)」「分(M)」「秒(S)」「合計(秒)」「占領時間」「確定まで」とする |
| OCC-021 | 首位の同盟の行を強調表示する |
| OCC-022 | 表の下に「合計経過」と「残り時間」を秒と`H:MM:SS`で表示する。`H:MM:SS`は四捨五入し、負の値は0として表す |

### 3.4 保存

| ID | 要件 |
|---|---|
| OCC-030 | 試合時間と同盟の入力を入力のたびにlocalStorageのキー`kvkOccupationState`へ保存し、次回表示時に復元する |
| OCC-031 | 保存形式は`{matchHours, alliances: [{name, h, m, s}]}`とし、入力欄の文字列をそのまま保存する。同盟が5件でない保存データは使わず、既定値を表示する |

## 4. 既知の不具合と現行実装との差異

| ID | 内容 | 影響 |
|---|---|---|
| KI-OCC-01 | 残り時間をすべて取っても逆転できない場合も「{分}分」と表示し、逆転不可能であることを示さない | 誤った判断 |
| KI-OCC-02 | 同率首位どうしでは「確定！」にならないことが画面から分からない | 読み違い |
| KI-OCC-03 | 「その他」の行も1つの同盟として首位や比較相手になる | 判定の前提が不明確 |
| KI-OCC-04 | 同盟名を`innerHTML`へエスケープせずに埋め込むため、`"`などを含む名前で表示が壊れる | 表示崩れ、安全性 |
| KI-OCC-05 | 分と秒の範囲（0〜59）を検証せず、負数や小数もそのまま計算する。小数では合計秒に浮動小数の誤差が出る | 入力範囲が不明確 |
| KI-OCC-06 | 残り時間が負になると、秒は負の値、`H:MM:SS`は0:00:00と表示がそろわない | 読み違い |
| KI-OCC-07 | 全同盟が0かつ残り時間が0の場合、全同盟が首位で「1分」と表示する | 境界値の誤表示 |
| KI-OCC-08 | 入力をまとめて初期化する操作がない | 次の試合での入力の手間 |
