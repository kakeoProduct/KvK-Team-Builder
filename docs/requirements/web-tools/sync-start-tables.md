# 要件定義: KvK同着スタート カウントアップ表／カウントダウン表

| 項目 | 内容 |
|---|---|
| 対象ファイル | `web/王城到着同期カウントアップ.html`、`web/KvK同着スタート カウントダウン表.html` |
| 表示名 | 「KvK同着スタート カウントアップ表」、「KvK同着スタート カウントダウン表」 |
| 状態 | 稼働中 |
| 要件ID接頭辞 | `SYNC` |
| 現行仕様の確認日 | 2026-10-17（コードの読解による。ブラウザでの動作確認は未実施） |

2つのツールは名簿入力と「誰が何秒目に出発するか」の計算が同一で、結果表の1列目とチャット用
テキストの表し方だけが異なる。このため1つの文書で定義し、差異は該当する要件に明記する。

## 1. 目的と利用場面

行軍時間が異なる複数のメンバーが、目標へ同時に到着できるよう、各自の出発タイミングを秒単位で
示す。行軍が最も長いメンバーが最初に出発し、短いメンバーほど待ってから出発する。結果は一覧表と、
ゲーム内チャットへ貼り付けるテキストで出力する。

- カウントアップ表: 最初に出発するメンバーを0秒とし、経過秒数で出発順を示す
- カウントダウン表: 最後に出発するメンバーを0秒とし、残り秒数で出発順を示す

## 2. 用語

| 用語 | 意味 |
|---|---|
| 到着秒数 | メンバーが出発してから目標に着くまでの行軍秒数 |
| 到着+ | 到着秒数へ加える補正秒数。用途は画面上で説明されていない（Q-SYNC-01） |
| 実際秒数 | `到着秒数 + 到着+` |
| 攻めグループ／駐屯グループ | 同着させたい単位。同じ文字列を入力したメンバーを同じグループとみなす |
| 未所属 | グループ欄が空、`ー`（全角長音）、`未所属`、`-`（半角）、`なし`のいずれか |
| カウント | 出発のタイミングを表す整数秒 |

## 3. 機能要件

### 3.1 名簿入力（両ツール共通）

| ID | 要件 |
|---|---|
| SYNC-001 | 名簿は1行1メンバーで、「名前」「到着秒数」「到着+」「攻めグループ」「駐屯グループ」を入力できる |
| SYNC-002 | 「＋行を追加」で空行（名前空、到着秒数0、到着+0、グループ空）を末尾へ追加できる |
| SYNC-003 | 各行の「削除」でその行を削除できる |
| SYNC-004 | 名前が空、または到着秒数が数値でない行は計算から除外する |
| SYNC-005 | 到着+が空または数値でない場合は0として扱う |
| SYNC-006 | 「最大カウント秒」で表に出すカウントの上限を指定できる。既定値は120、入力欄の範囲は1〜600 |
| SYNC-007 | 初回表示時（保存データがないとき）は、確認用のサンプル名簿5行を表示する |

### 3.2 計算規則（両ツール共通）

| ID | 要件 |
|---|---|
| SYNC-010 | 全体の基準は、有効なメンバーの実際秒数の最大値とする |
| SYNC-011 | 全体カウントは `全体の基準 - 実際秒数` とする。0が最初に出発するメンバーになる |
| SYNC-012 | グループは攻めと駐屯それぞれで、未所属以外の値を名簿の出現順に重複なく列挙する |
| SYNC-013 | グループの基準は、そのグループに所属するメンバーの実際秒数の最大値とする |
| SYNC-014 | グループカウントは `グループの基準 - 実際秒数` とする |
| SYNC-015 | 計算はページ表示時と「計算する」押下時に行う。入力変更だけでは再計算しない |

### 3.3 出力: カウントアップ表

| ID | 要件 |
|---|---|
| SYNC-020 | 結果表の列は「秒」「全体」、攻めグループごとの「{グループ名}(攻)」、駐屯グループごとの「{グループ名}(駐)」とする |
| SYNC-021 | 行は0から最大カウント秒までのすべての秒を出し、該当者がいない秒も表示する |
| SYNC-022 | 該当者は「、」で連結して強調表示し、いない場合は「なし」と表示する |
| SYNC-023 | チャット用テキストは「全体」、攻めの各グループ、駐屯の各グループの順に1つずつ作る |
| SYNC-024 | チャット用テキストの書式は次のとおり。該当行だけをカウントの昇順で並べ、該当者がいなければ本文を「（到着者なし）」とする |

```text
ーー
0秒：みっちゃん
7秒：あお、しろ、くろ
8秒：さくら
ーー
```

### 3.4 出力: カウントダウン表

| ID | 要件 |
|---|---|
| SYNC-030 | 最後の出発カウントを `全体の基準 - 実際秒数の最小値` とし、1列目の値を `最後の出発カウント - 全体カウント` とする |
| SYNC-031 | 1列目の見出しは「最後の出発まで」とし、値が0の行を強調表示する |
| SYNC-032 | 行の範囲は全体カウント0から `min(最大カウント秒, 最後の出発カウント)` までとする |
| SYNC-033 | チャット用テキストは「{1列目の値}秒：{名前}」を値の降順で並べ、前後の「ーー」と「（到着者なし）」はカウントアップ表と同じとする |

### 3.5 操作

| ID | 要件 |
|---|---|
| SYNC-040 | チャット用テキストごとに「コピー」ボタンを置き、クリップボードへコピーできる |
| SYNC-041 | コピー後は1.2秒間、ボタン表示を「コピーしました」に変える |
| SYNC-042 | チャット用テキストは手で編集できる |

### 3.6 保存

| ID | 要件 |
|---|---|
| SYNC-050 | 名簿と最大カウント秒を入力のたびにlocalStorageへ保存し、次回表示時に復元する |
| SYNC-051 | 保存キーはカウントアップ表が`kvkCountupRosterState`、カウントダウン表が`kvkCountdownRosterState`とし、2つのツールで名簿を共有しない |
| SYNC-052 | 保存形式は`{"roster": [[名前, 到着秒数, 到着+, 攻め, 駐屯], ...], "maxSec": "<文字列>"}`とし、入力欄の文字列をそのまま保存する。計算結果は保存しない |

## 4. 例外と境界値

| ID | 要件 |
|---|---|
| SYNC-060 | 有効な行が0件の場合、結果表に「名簿を入力してください」と表示し、チャット用テキストを出さない |
| SYNC-061 | 最大カウント秒が0、空欄、数値以外の場合は120として扱う |

## 5. 既知の不具合と現行実装との差異

| ID | 内容 | 影響 |
|---|---|---|
| KI-SYNC-01 | 最大カウント秒を復元するとき、復元途中の行追加で既定値120が保存される。操作せずに再読み込みすると120へ戻る | SYNC-050を満たさない |
| KI-SYNC-02 | カウントが最大カウント秒を超えるメンバーは、警告なしで表とチャット用テキストから消える | 出発指示の漏れ |
| KI-SYNC-03 | 実際秒数が小数の場合、整数のカウントと厳密比較するため、どの行にも表示されない | 出発指示の漏れ |
| KI-SYNC-04 | 名前を`innerHTML`へエスケープせずに埋め込むため、`"`や`<`を含む名前で表示が壊れ、HTML注入が起きる | 表示崩れ、安全性 |
| KI-SYNC-05 | 名簿の全行を削除して再読み込みすると、サンプル名簿に戻る | 意図の確認が必要（Q-SYNC-03） |
| KI-SYNC-06 | クリップボードへのコピーが失敗しても「コピーしました」と表示する | 誤ったFeedback |
| KI-SYNC-07 | カウントダウン表で、グループ列はグループの基準で判定するが、1列目は全体の基準で表示するため、同じメンバーが全体列とグループ列で別の秒数になる。サンプルでは全体列で0秒の「さくら」がグループ列では8秒になる | 誤った出発指示の恐れ |
| KI-SYNC-08 | カウントダウン表で最大カウント秒が最後の出発カウントより小さいと、0側（最後に出発するメンバー）が切り捨てられる | 出発指示の漏れ |
| KI-SYNC-09 | カウントダウン表で値0の行は緑の強調が黄色の該当者強調を上書きする | 視認性 |
| KI-SYNC-10 | `－`（全角ハイフンマイナス）や`—`は未所属とみなされず、グループ名として扱われる | 意図しない列の追加 |
| KI-SYNC-11 | ファイル名「王城到着同期カウントアップ」と表示名「KvK同着スタート カウントアップ表」が一致しない | 保守時の混乱 |
| KI-SYNC-12 | 最大カウント秒に負数を入れると行が出ず、601以上も拒否しない | 入力範囲が不明確 |
