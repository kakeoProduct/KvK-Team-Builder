| 項目 | 内容 |
|---|---|
| 対象ファイル | `web/周期ウェーブタイマー.html` |
| 表示名 | 「周期ウェーブタイマー」 |
| 状態 | 稼働中 |
| 要件ID接頭辞 | `WAVE` |
| 現行仕様の確認日 | 2026-10-25（タブ、計算元の読み込み、保存は`tests/web/`の検査で実物のHTMLを動かして確認。2つのタブの同時の計測、計算元の読み込みと更新の表示、900px以下での貼り付け欄の非表示と計算元の欄の表示、横にはみ出さないこと、低モーションの設定、矢印キーでのタブの切り替え、旧形式の注意（WAVE-077）、2つのページで開いたときの計測を続けたままの読み直しと削除の知らせ（WAVE-053）は、Chromium 130でDesktop幅（1280px）とMobile幅（390px）で確認（COM-053）。それ以外は2026-10-17のコードの読解による） |

## 1. 目的と利用場面

一定の周期で発生する予定（ウェーブ）ごとの経過時間を並べて表示する。スタートで1個目の予定が
始まり、周期ごとに次の予定を自動で追加し、一定時間を過ぎた予定を消す。あわせて、
[集結タイムライン計算](siege-timeline.md)の結果を読み込むか貼り付けると、パターン①②③…の
進行状況と次の周までの残り時間を表示する。

1つのページの中にタブで複数のタイマーを持ち、それぞれ独立に計測できる。

## 2. 用語

| 用語 | 意味 |
|---|---|
| 予定 | 周期ごとに追加される経過時間のカウンター |
| 周期 | 予定を追加する間隔。設定欄で入力する |
| MAX | 予定の寿命の基準となる秒数 |
| 表示延長 | MAXを過ぎても予定を表示し続ける秒数。画面では「MAX＋◯秒まで表示」 |
| タイムライン | 集結タイムライン計算から読み込んだか貼り付けたテキスト |
| タイムラインの1周 | タイムライン中の`周期：`行の値。設定欄の周期とは独立している |
| タブ | ページ内で切り替えるタイマー。設定、タイムライン、計算元、計測の状態をタブごとに持つ |
| 計算元 | タイムラインを読み込んだ、集結タイムライン計算のタブ |

## 3. 機能要件

### 3.1 設定

| ID | 要件 |
|---|---|
| WAVE-001 | 「周期」（分、秒）、「MAX」（分、秒）、「MAX＋◯秒まで表示」（秒）を入力できる。既定値は周期10秒、MAX30秒、表示延長3秒 |
| WAVE-002 | 設定値はスタート時に確定する。周期とMAXは`分 × 60 + 秒`を整数で求め、1秒未満は1秒とする。表示延長は0秒未満を0秒とする |
| WAVE-003 | 表示中のタブが計測中の間は、そのタブの周期、MAX、表示延長の入力欄を編集できない。計算元の選択と「読み込む」（WAVE-070、WAVE-071）は計測中も使える |

### 3.2 予定の追加と削除

| ID | 要件 |
|---|---|
| WAVE-010 | スタート時刻を基準とし、k個目の予定を`スタート時刻 + (k - 1) × 周期`に追加する。1個目はスタートと同時に追加する |
| WAVE-011 | 予定の時刻は基準時刻からの絶対時刻で決め、ブラウザのタブの休止などで遅れても誤差を積み重ねない |
| WAVE-012 | 予定の経過時間が`MAX + 表示延長`に達したら、その予定を消す |
| WAVE-013 | 各予定の経過時間を`MM:SS.t`（0.1秒単位、切り捨て）でカウントアップ表示する |
| WAVE-014 | 予定がない場合は「まだ予定がありません」と表示する |

### 3.3 操作

| ID | 要件 |
|---|---|
| WAVE-020 | 「スタート」で表示中のタブの予定を初期化し、計測を始める。計測中の押下は無視する |
| WAVE-021 | 「ストップ」で表示中のタブの予定の追加を止め、予定とタイムラインの経過時間を停止時点で凍結表示する |
| WAVE-022 | ストップ後に「スタート」を押すと、予定を消して最初から計測する |
| WAVE-023 | 「リセット」で表示中のタブの計測を止め、予定とタイムラインの進行表示を消す |

### 3.4 タイムラインの貼り付けと解析

| ID | 要件 |
|---|---|
| WAVE-030 | 貼り付け欄には表示中のタブのタイムラインを表示する。入力のたびにそのタブへ保存し、解析して表示を更新する。保存に成功したら「保存しました」、失敗したら「この環境では保存できません」を1.5秒間表示する |
| WAVE-031 | 行頭が`①`〜`⑩`の行をパターンの見出しとし、次の見出しまでをそのパターンのブロックとする |
| WAVE-032 | ブロック内で行頭が`{分}分{秒}秒`または`{分}:{秒2桁}`の行を時刻行とする。最初の時刻行をパターンの開始、時刻の最大値をパターンの終了とする。時刻行のないブロックは除外する |
| WAVE-033 | テキスト中の`周期：{分}分{秒}秒`または`周期：{分}:{秒2桁}`をタイムラインの1周として最優先で使う。`分秒`形式を`:`形式より優先する |
| WAVE-034 | `周期：`行がない場合は、`最後のパターンの終了 - 最初のパターンの開始`を1周とする。この値は行軍、帰還、待ち時間を含まず、実際の周期より短い |
| WAVE-035 | 画面幅が900px以下の場合は貼り付け欄を表示しない。保存済みのタイムラインの解析と表示は続ける |
| WAVE-036 | 貼り付け欄の文字サイズを16pxから8pxまでの範囲で、欄に収まるよう自動で調整する |

### 3.5 パターンの進行表示

| ID | 要件 |
|---|---|
| WAVE-040 | タイムラインの0秒をスタート時刻とし、1周を無限に繰り返す前提で現在の周内の位置を求める |
| WAVE-041 | 現在の周でまだ終了していないパターンの見出しを、最も古い予定のカードの右側に並べる |
| WAVE-042 | 現在の周で終了したパターンは、「2周目」ラベル付きのカードにまとめ、次の周で最も早く始まるパターンまでの残り時間を`-MM:SS.t`でカウントダウン表示する |
| WAVE-043 | 解析できるパターンがない場合は「タイムラインのテキストが貼り付けられていません」と表示する |

### 3.6 タブ

| ID | 要件 |
|---|---|
| WAVE-060 | ページ内のタブで複数のタイマーを切り替えられる。各タブは設定、タイムライン、計算元、計測の状態をすべて独立に持ち、あるタブの操作は他のタブへ影響しない |
| WAVE-061 | 各タブは独立に計測し、表示していないタブも計測を続ける。表示を戻すと、その時点の予定と経過時間を表示する |
| WAVE-062 | 計測中のタブの見出しには、名前に続けて「▶」とスタートからの経過時間（`MM:SS.t`）を表示する。計測中かどうかを色だけで区別しない |
| WAVE-063 | 「+ タブ追加」で、設定が既定値でタイムラインが空の新しいタブを末尾へ追加して表示する。名前は追加した順の通し番号で「タイマー1」「タイマー2」…とし、タブを削除しても番号を再利用しない |
| WAVE-064 | 表示中のタブの名前を「タブ名」の欄で変更できる。名前を空にした場合は、そのタブの既定の名前（「タイマー{番号}」）を表示する |
| WAVE-065 | 「このタブを削除」で表示中のタブを削除できる。削除の前に確認を出し、取り消した場合は何も変えない。タブが1つだけの場合は削除できない。計測中のタブを削除すると計測も終える。削除後は、削除したタブの右隣、なければ左隣のタブを表示する |
| WAVE-066 | タブの切り替えをキーボードで行える。タブの並びにFocusがあるとき、左右の矢印キーで前後のタブ、HomeとEndで先頭と末尾のタブへ移って表示する。末尾で右の矢印キーを押すと先頭へ、先頭で左の矢印キーを押すと末尾へ移る。Focusを表示する |

### 3.7 計算元の読み込み

| ID | 要件 |
|---|---|
| WAVE-070 | 設定欄に「計算元」の選択欄と「読み込む」ボタンを置き、集結タイムライン計算の保存データ（`siegeCalcTabs`、SIEGE-041）にあるタブを名前で選べる。読み込める計算結果がないタブ（WAVE-072）は、名前に「（計算結果なし）」を付ける。この欄は画面幅900px以下でも表示する。保存データにタブがない場合は「集結タイムライン計算のタブがありません」と表示し、読み込めない |
| WAVE-071 | 「読み込む」を押すと、その時点の計算元の「計算結果（1周目）」を表示中のタブのタイムラインとして取り込み、貼り付け欄の内容を置き換えて保存する。以後、計算元で計算し直しても、取り込んだタイムラインと計測中の表示は変わらない。計測中に「読み込む」を押した場合は、その時点でタイムラインを置き換え、進行表示も新しいタイムラインで続ける |
| WAVE-072 | 選んだタブに読み込める計算結果がない場合（未計算、またはSIEGE-032、SIEGE-033のメッセージ）は、取り込まずに「このタブには読み込める計算結果がありません」と表示する |
| WAVE-073 | 計算元の状態を設定欄に文字で表示する。読み込んだ後に計算元で計算し直され、読み込める結果が出た場合は「⚠ 計算元が更新されています。もう一度読み込むと反映します」、計算し直した結果が読み込めないもの（SIEGE-032、SIEGE-033）だった場合は「⚠ 計算元の最新の計算は結果を出せませんでした。読み込み済みのタイムラインを使っています」、計算元のタブが削除された場合は「⚠ 計算元のタブ「{名前}」は削除されています」、それ以外は「計算元：{名前}から読み込み済み」とする。計算元がなく、WAVE-077の注意も出さない場合は何も表示しない |
| WAVE-074 | 計算元の一覧と状態の表示は、ページの表示時、タブの切り替え時、集結タイムライン計算の保存データが変わったとき（別のブラウザのタブでの計算を含む）に更新する |
| WAVE-075 | 貼り付け欄を手で編集した場合は、そのタブの計算元との関連を外す |
| WAVE-076 | 集結タイムライン計算の保存データは読むだけで、書き換えない |
| WAVE-077 | 旧キー`waveTimerPastedTimeline`から移したタイムライン（WAVE-052）が空白だけでなければ、そのタブの計算元の状態の欄に「⚠ 旧形式から移したタイムラインです。集結タイムライン計算で計算し直して読み込んでください」と表示する。旧形式のタイムラインは、確定順と周期の求め方を直す前（SIEGE-013、SIEGE-017）の計算の結果のためである。貼り付け欄を手で編集するか、計算元を読み込むと表示を消す。ページを開き直しても表示を続ける |

### 3.8 保存

| ID | 要件 |
|---|---|
| WAVE-050 | すべてのタブ（名前、設定、タイムライン、計算元、旧形式の注意の有無）と、最後に表示していたタブを、変更のたびにlocalStorageのキー`waveTimerTabs`へ保存し、次回表示時に復元する。計測の状態は保存せず、ページを開き直したときはすべてのタブが停止している |
| WAVE-051 | 保存形式は次のとおりとする。`timelineText`は貼り付け欄の内容をそのまま持つ。`source`は計算元がなければ`null`とし、`revision`は読み込んだ時点の計算元の版番号（SIEGE-041）とする。`legacyTimeline`は旧形式から移したタイムラインのままか（WAVE-077）を表す真偽値で、ない場合は`false`として扱う。タブの`id`は、別のブラウザのタブで作ったタブとも重ならない値とする |
| WAVE-052 | `waveTimerTabs`がないか、読めない（空、または壊れている）場合は、旧キー`waveTimerSettings`の設定と旧キー`waveTimerPastedTimeline`のテキストを最初のタブ「タイマー1」へ移す。旧キーがない項目は既定値とする。旧キーは読むだけで、書き換えも削除もしない |
| WAVE-053 | 同じページを別のブラウザのタブで開いていて、そちらで`waveTimerTabs`が保存されたら、その保存データで表示を読み直す。表示中のタブが残っていればそのタブを表示し続け、なければ保存データの最後に表示していたタブを表示する。計測中のタブは同じidのタブで、スタート時の設定のまま計測を続け（WAVE-002）、設定欄には計測に使っている設定を表示する。タイムラインは置き換える（WAVE-071と同じ）。保存データにない計測中のタブは計測を終え、「⚠ 計測中のタブ「{名前}」は、別のブラウザのタブで削除されたため計測を終えました」と表示する。この表示を消す前に続けて計測を終えたタブは、名前を「{名前1}」「{名前2}」と並べる。この表示はタブの切り替え、追加、削除で消す。読めない保存データは無視する。別のページへ移って戻ったとき（ブラウザがページを復元したとき）も読み直す |

```text
{version: 1, tabSeq, activeTabId,
 tabs: [{id, seq, name,
         settings: {periodMin, periodSec, maxMin, maxSec, extraDisplaySec},
         timelineText,
         source: null | {siegeTabId, siegeTabName, revision},
         legacyTimeline}]}
```

旧キー`waveTimerSettings`の形式は`{periodMin, periodSec, maxMin, maxSec, extraDisplaySec}`、
旧キー`waveTimerPastedTimeline`は貼り付けたテキストそのものである。

## 4. 既知の不具合と現行実装との差異

| ID | 内容 | 影響 |
|---|---|---|
| KI-WAVE-01 | 副題は「各予定はMAX秒で消えます」だが、実際は`MAX + 表示延長`で消える。MAXに達した時点で表示が変わらない | MAXの到達が分からない |
| KI-WAVE-02 | 次の周を待つカードは3周目以降も「2周目」と表示する | 読み違い |
| KI-WAVE-03 | `周期：`行がない場合、終了が最も遅いパターンは待機表示に入らない。全パターンが同時刻の場合は1周が1秒になる | 誤った進行表示 |
| KI-WAVE-04 | まだ始まっていないパターンと進行中のパターンを区別せずに表示する | 読み違い |
| KI-WAVE-05 | 予定のカードがない間は、未終了のパターンが表示されない | 情報の欠落 |
| KI-WAVE-06 | 予定の「N個目」は表示中の並び順であり、古い予定が消えると番号が詰まる | 何番目のウェーブか分からない |
| KI-WAVE-07 | 一時停止と再開ができない。ストップ後のスタートは最初からになる | 中断後に続けられない |
| KI-WAVE-08 | `周期：`は行頭でなくても一致するため、「攻撃周期：」のような文字列も拾う | 誤った1周 |
| KI-WAVE-09 | パターンの見出しは`⑩`までしか認識しない。集結タイムライン計算は`⑳`まで出力できる | 11個目以降のパターンの欠落 |
| KI-WAVE-10 | 時刻行が昇順でない場合、パターンの開始が最小値にならない | 誤った進行表示 |
| KI-WAVE-11 | 貼り付けた、または計算元から読み込んだ見出しを`innerHTML`へエスケープせずに挿入する | 表示崩れ、安全性 |
| KI-WAVE-12 | テキストを貼り付けても解析に失敗すると「貼り付けられていません」と表示し、原因が分からない | 誤ったFeedback |
| KI-WAVE-13 | 待機中のパターンが複数あっても、カウントダウンは最も早いもの1つだけを表示する | 個別の残り時間が分からない |

## 7. 作成者の仮定

出典と決定済みの事項から一つに決まらなかった細部を、作成者が次のとおり決めた。運用者が覆せる。

| 要件 | 仮定 |
|---|---|
| WAVE-050 | 計測の状態は保存しない。ページを開き直したときは、すべてのタブが停止している（従来と同じ）。ページ内でタブの表示を戻したとき（WAVE-061）と、ブラウザがページを復元したとき（WAVE-053）は計測を続ける |
| WAVE-051 | タブの`id`は、`w{番号}-`に作った時刻と乱数を続けた文字列とする。重なる確率は無視できる程度とし、完全な一意性は保証しない |
| WAVE-052 | 旧キーから移すのは、新しいキーがないか読めない場合だけとする。移した後は新しいキーを使う |
| WAVE-053 | 別のブラウザのタブでの保存への対処として、警告を出す方式ではなく読み直す方式を、作成者が選んだ（リリースのレビューへの対応、2026-10-25）。読み直している間は保存し直さない。保存し直すと、保存の通知がブラウザのタブの間で往復するため。読み直しは後から保存した側の内容になり、同時に別々の変更をした場合は後の保存が残る |
| WAVE-063 | 新しいタブは、設定を既定値、タイムラインを空として始める |
| WAVE-064 | 名前を空にしたときは、保存する名前を空のままにし、表示だけ既定の名前にする |
| WAVE-065 | タブが1つだけのときは削除できない。削除後は右隣、なければ左隣のタブを表示する |
| WAVE-066 | 矢印キーは端から反対の端へ回り込む |
| WAVE-071 | 計測中の読み込みは、計測を止めずにタイムラインだけを置き換える |
