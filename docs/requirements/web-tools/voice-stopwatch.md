## 1. 目的と利用場面

指定した秒数に達したとき、指定した文言を音声で読み上げるストップウォッチとする。メニューの
説明は「指定秒数で指定した文言を音声読み上げ（複数設定可）」である。

## 2. 現行の状態

本文は「工事中です。しばらくお待ちください。」の表示だけで、入力、計時、音声、保存は
実装されていない。2026-09-01に運用者の指示で工事中の表示へ差し替えた。

| ID | 要件 |
