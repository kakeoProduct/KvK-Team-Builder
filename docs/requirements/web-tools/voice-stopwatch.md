# 要件定義: 音声アナウンス付きストップウォッチ

| 項目 | 内容 |
|---|---|
| 対象ファイル | `web/音声アナウンス付きストップウォッチ.html` |
| 表示名 | ページは「音声アナウンス付きストップウォッチ」、サイドバーは「音声ストップウォッチ（工事中）」 |
| 状態 | 工事中 |
| 要件ID接頭辞 | `VOICE` |
| 現行仕様の確認日 | 2026-10-17（コードの読解による） |

## 1. 目的と利用場面

指定した秒数に達したとき、指定した文言を音声で読み上げるストップウォッチとする。メニューの
説明は「指定秒数で指定した文言を音声読み上げ（複数設定可）」である。

## 2. 現行の状態

本文は「工事中です。しばらくお待ちください。」の表示だけで、入力、計時、音声、保存は
実装されていない。2026-09-01に運用者の指示で工事中の表示へ差し替えた。

## 3. 機能要件

| ID | 要件 |
|---|---|
| VOICE-001 | 工事中の間は、ページとメニューのカードに工事中であることを表示する |

機能の要件は未定義である。実装を始める前に、次の未決事項を決めて本書へ追記する。

## 4. 既知の不具合と現行実装との差異

| ID | 内容 | 影響 |
|---|---|---|
| KI-VOICE-01 | ページ名「音声アナウンス付きストップウォッチ」とサイドバー名「音声ストップウォッチ（工事中）」が一致しない | 共通要件COM-020を満たさない |

## 5. 未決事項

| ID | 問い |
|---|---|
| Q-VOICE-01 | 読み上げの設定（秒数と文言）を何件まで持てるか |
| Q-VOICE-02 | 計時はカウントアップとカウントダウンのどちらか。繰り返しを設けるか |
| Q-VOICE-03 | 音声はブラウザの音声合成（Web Speech API）を使うか。対応しないブラウザでの代替を設けるか |
| Q-VOICE-04 | 周期ウェーブタイマーや集結タイムライン計算の出力と連携するか |
