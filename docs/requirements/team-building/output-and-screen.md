# 要件定義: 出力と画面

アプリの最終出力はチャット共有用テキストだけとする（利用者の決定、2026-10-18）。Excelは出力しない。
運用でExcelの「時間帯別稼働」「チーム名簿」「別枠」シートが担っていた確認と調整は、画面で行う。

## 1. チャット共有用テキスト

| ID | 分類 | 要件 |
|---|---|---|
| OUT-001 | 表示のみ | 隊ごとに「第○隊 リーダー:○○」の見出しと、メンバーの行を出す（旧Q-039、旧Q-052で決定）。別枠に置いたリーダーの隊は、見出しを「第3隊 リーダー不在」の形にする（旧Q-062、旧Q-074で決定） |
| OUT-002 | 表示のみ | メンバーは「名前◇★(参加時間)」の形で「、」区切りに並べる。◇と★は持っている場合だけ付ける。全時間参加のメンバーは参加時間を書かない。24時以降の時刻は24:30のように書く（ROS-022） |
| OUT-003 | 表示のみ | 1つのコードブロックに含める改行は10個以内とし、超える場合はブロックを分ける |
| OUT-013 | 表示のみ | 隊の中のメンバーは、◇と★を両方持つメンバー、どちらかを持つメンバー、どちらも持たないメンバーの順に並べる。同じ区分の中はGの高い順とし、同じGは参加者一覧の出現順とする。同盟メンバー表（OUT-014）の各行にも同じ順を当てはめる（旧Q-052、旧Q-057、旧Q-064で決定） |
| OUT-014 | 表示のみ | チャット共有用テキストに、同盟メンバー表（同盟別・兵士レベル別、参加区分ごとのブロック、ROS-010〜ROS-013の記号と括弧の順）も出す（旧Q-052で決定）。該当者がいないGの行も空のまま出し、「その他」の行は両方のブロックに付ける。総力モードでは総力（OUT-008）を付ける。時刻は24:30の形（OUT-002）で書く。別枠と待機のメンバーも載せる（旧Q-065で決定）。同盟移動協力者の欄は出さず、同盟は参加者一覧に最初に現れた順に並べる（旧Q-078で決定）。チャット共有用テキストの一部なので、OUT-003の改行の制限を当てはめる |
| OUT-004 | 表示のみ | 見出しに「◯最低N」（FRM-056）を付ける。延長境界時刻以降の値Mが違う場合は「(24時以降M)」のように延長境界時刻を添えて付ける |
| OUT-005 | 表示のみ | 総力モードでグループがある場合は、グループ別に「【グループ名】◯最低N Nx4分=X時間Y分」の形で合計を表示する。グループの値は、グループに属する各隊のNの合計とし、4分を掛けた値は治療時間の目安を表す（旧Q-007で決定）。テキストと画面の両方に表示する。通常モードと、総力モードでグループがない場合は、自動では表示しない。通常モードでは、運用者が画面でグループを作ったときだけ、UI-013で画面に表示する（旧Q-019、旧Q-041、旧Q-054で決定）。Nは21:00〜24:00の値とする（FRM-056、旧Q-046） |
| OUT-006 | 表示のみ | 末尾に「※括弧内は参加時間。記載なしは全時間」「※所属は固定。各隊はその時間に参加できるメンバーから8〜○名で出撃」の注記を付ける。○は全隊共通の上限（FRM-030。例: 10）とし、上限を上書きした隊があれば、「8〜10名（第6隊は8名、第7隊は9名）」の形で番号順に併記する（旧Q-063、旧Q-074で決定） |
| OUT-007 | 表示のみ | 応援するメンバー（FRM-042）と、遅れて出撃する隊とその出撃開始時刻（FRM-041、FRM-048）、休止した時間帯（FRM-048）、隊数を減らしてなくした隊（FRM-005）、使わなかった運用者の指定（FRM-046の「許しは不要になった」、FRM-090、隊数を減らして失効した指定（A-03））を、テキストから分かるようにする。使わなかった指定は警告ではなく注記とし、画面にも示す |
| OUT-008 | 表示のみ | 総力モードでは、各メンバーの末尾に総力（例: `491.3M`）を付ける |
| OUT-009 | 表示のみ | 別枠（参加時間未定）と待機の人数と名前を示す。総力モードでグループがある場合はグループごとにまとめる |
| OUT-010 | 必須条件 | 出力する前に要件全体を自動で検査し、必須条件の違反が0件であることを確認する。違反があれば出力しない。運用者が明示した例外（FRM-036の上限超え、FRM-046の下限未満）は違反ではなく警告として扱う。FRM-005で減らした隊は、FRM-001の対象から外す |
| OUT-011 | 表示のみ | 警告（FRM-029、FRM-035、FRM-036、FRM-043、FRM-046、FRM-049、FRM-053など）は、チャット共有用テキストと画面の両方に示す（旧Q-008で決定） |
| OUT-012 | 廃止 | 作業中の確認をコードブロックで示し、最終まとめをファイルで出力する規則は採用しない。前半は対話の手順でありアプリの要件ではない。後半は、最終出力をチャット共有用テキストだけとする決定（本書の冒頭）により置き換える |

## 2. 時間帯別稼働の画面

Excelの「時間帯別稼働」シートが示していた情報を画面で確認し、隊の調整を画面上で行えるようにする。
画面の実装は#16（チーム編成結果）と#15（チーム編成の実行）で行い、`$apple-design`の基準を適用する。
画面はアプリケーションのユースケースを呼び出し、編成ルールや警告の判定を画面へ複製しない。

| ID | 分類 | 要件 |
|---|---|---|
| UI-001 | 表示のみ | 時間帯ごとに、全体の出撃人数、8〜上限（隊ごとの上書きを含む）の人数で組める隊の数、隊ごとの出撃人数の内訳を示す |
| UI-002 | 表示のみ | 時間帯ごとに抜けるメンバーの人数を示す |
| UI-003 | 表示のみ | 隊ごとに、所属人数、時間帯ごとの出撃人数と平均G、VC可能人数、◯最低、★の人数、上位隊の条件を示す |
| UI-004 | 表示のみ | 隊の名簿を、時間帯ごとの出撃（○）と応援が分かる表で示す。リーダーと、リーダー不在の時間帯（FRM-002）を区別する。別枠に置いたリーダーの隊は「リーダー不在」と示す。休止した時間帯と、遅れて出撃する隊の出撃開始時刻を示す（FRM-048） |
| UI-005 | 表示のみ | 出撃8人未満の時間帯、★のいない時間帯、上限超えなどの警告を、色だけに頼らず文言とアイコンで区別する |
| UI-006 | 運用操作 | メンバーを別の隊へ移動できる。移動する前に、影響する時間帯の出撃人数と警告の変化を、アプリケーションのユースケースで計算して示す |
| UI-007 | 運用操作 | 隊のFIX、メンバーのセット、隊数を減らす選択（FRM-005）、下限未満の明示的な許容（FRM-046。許したときの人数を示して指定に含める）を画面で指定できる |
| UI-008 | 運用操作 | 遅れて出撃する隊、出撃開始時刻、応援先（FRM-041、FRM-042）を画面で選べる。応援先を決める必要がある場合は、出力の前にダイアログで問い合わせ、選ぶまで出力しない（旧Q-033で決定） |
| UI-009 | 必須条件 | 画面で変更した編成は、Validatorで独立に再検証してから出力する。画面で変えた運用者の指定も、CLIの回答と同じ確かめ方（FRM-047、FRM-090）でアプリケーションが受け入れてから、Validatorへ渡す。必須条件の違反がある間はテキストを出力しない。運用者が明示した例外（FRM-036、FRM-046）は警告として扱う |
| UI-010 | 運用操作 | 変更前の編成と比べた差分（移動、リーダーの変更、欠落）を示す |
| UI-011 | 表示のみ | 時間帯ごとの出撃（○）は参加時間から計算し、画面で直接編集しない（旧Q-025で決定）。参加時間を直すと出撃を計算し直す |
| UI-012 | 表示のみ | 別枠と待機を、隊とは別の一覧で示す |
| UI-013 | 表示のみ | 通常モードでも、編成の後に画面で隊を選んでグループを作れる。このグループはFRM-004のグループと同じもので、編成と必須条件（FRM-081〜FRM-086）に影響しない（旧Q-054で決定）。「治療時間を計算」ボタンを押すと、グループ別の◯最低の合計と治療時間の目安をOUT-005の形で、アプリケーションのユースケースで計算し、画面に示す（旧Q-041で決定） |
