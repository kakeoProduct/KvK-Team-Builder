# Codespaces認証対応のPR作成Skillを追加

## 利用者の依頼

GitHub Pull Requestの本文項目と安全なCodespaces認証を設計し、共有Skillとして実装する

## 実装結果

create-github-pr Skill、PRテンプレート、共有規約、ADR、回帰Testを追加した

## 重要な判断

- 認証情報は.envへ保存せず、Repository限定のCodespaces Secret GH_TOKENを使用する
- 本文準備と外部作成を分離し、明示された場合だけ通常pushとPull Request作成を行う
- 品質ゲート未成功時はReadyを作らず、重複、force push、merge、Issue操作を防止する

## 検証

- quick_validate.py .agents/skills/create-github-pr: 成功
- python -m pytest tests/test_ai_harness.py -q: 7件成功
- python tools/check.py: Ruff、mypy、pytest 32件すべて成功
- gh api userとgh pr list: TOKEN非表示で認証とPR読み取りに成功
- 別Agentの読み取り専用フォワードテスト: 外部作用なしで停止条件を検出
