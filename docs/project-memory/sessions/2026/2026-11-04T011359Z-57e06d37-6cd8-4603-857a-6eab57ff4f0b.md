# Playwright MCPでweb/をブラウザ操作して確かめる環境を加える

## 利用者の依頼

取り込んだweb機能のレビューの後、実際のブラウザ操作で検証できるようChrome系MCPなどの導入を検討し、承認不要な範囲で進める

## 実装結果

DockerfileにDebianのchromiumと日本語・絵文字フォント、@playwright/mcp@0.0.83をlockで固定、.mcp.jsonと.codex/config.tomlに同じ引数で登録、ADR 0032、DEVELOPMENT.md、AGENTS.md、CLAUDE.md、architecture.mdを更新、構造テストを追加。未コミット

## 重要な判断

- Containerではseccompがuser namespaceを禁じsandboxを使えないため、利用者の選択で--no-sandboxと--allowed-origins http://127.0.0.1:8765を使う。上流は後者を安全境界ではないとしており、外部資源を読まない自作web/だけを開く前提をADRに作成者の仮定として記録
- npxは--no --で起動する（--がないとnpxが--executable-path等をnpmの設定として読む）。読み取り専用のレビュー担当はClaude CodeではHookがmcp__*を拒否、Codexは未強制
