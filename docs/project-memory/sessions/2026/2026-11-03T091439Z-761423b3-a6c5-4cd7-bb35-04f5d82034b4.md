# 取り込み元の補助ツールでweb/を置き換え、仕様書と検査を合わせる

## 利用者の依頼

許可を得た取り込み元のブラウザ用ツールをweb/へ取り込み、各ページのロジックの仕様書を作成または更新する。取り込んだ版の動作を正とし、諸々を直す

## 実装結果

要件定義書を書き直し（siege-timeline、wave-timer、新規sync-start-countdown（CDOWN）、sync-start-tables、occupation-judge、voice-stopwatch、README）、ADR 0031、domain-model、README、architecture、DEVELOPMENTを更新。tests/webを新しい要件で作り直した（79件）

## 重要な判断

- 範囲はtools/の7ツールだけ。GAS連携は外し、このブラウザだけに保存する（利用者の決定）
- 両方で変わった2ページも取り込み元の版で置き換え、タブと周期の修正は失った。取り込んだ版の動作を正とし、HTMLは変えず、意図と違う動作は既知の不具合（KI）へ記録する（利用者の決定）
- 公開済みの版のwaveTimerTabsが上書きで失われることを利用者が受け入れた
- （作成者の仮定）pet-bonus.jsは複写せず共通部品とし、COM-001を改めた。メニューの見出しは伏せる語の代わりに「攻城」。ペットのスキル名は除いた
- 自己点検リストにC17（提案の未検証）を加えた

## 検証

- python tools/check.py: 成功（pytest、tests/web 79件）
- Chromium 130（ヘッドレス、CDP）でDesktop 1280pxとMobile 390pxの主要な操作を確認。計測中の時短ボタンはマウスでは効かない（KI-WAVE-30）
- review-kvk-change: 再レビュー3回で承認候補（Must、Shouldなし）

## 未完了事項
