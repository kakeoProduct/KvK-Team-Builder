## 利用者の依頼

実装Issue 2のPR (b)。遅れて出撃する隊と応援、回答のファイル、FRM-075の番号付きの質問と終了コード、時間切れの共通の型、回答を確かめる手順、FRM-090の性質のテストの枠

## 実装結果

LateStartとSupportRefを運用者の指定に加え、OptimizerとValidatorで出撃開始前と応援を扱った。answers.jsonを--answersで読み、回答を対象の順に1つずつ確かめる。下限の不足は番号付きの質問で終了コード3、時間切れは4。ADR 0035、A-41、DAT-009、旧Q-145〜150を記録した

## 重要な判断

- 利用者の決定（2026-11-10）: PRを(b)と(c)に分ける、終了コード0/2/3/4、answers.jsonをsettings.jsonと分ける、序盤以外の休止も質問にして回答できないと示す、回答を確かめる手順の骨子
- （作成者の仮定）A-41: 序盤にない対象への回答は入力のエラー、同じ隊を遅らせる別の指定と同じメンバーの応援は受け入れない、受け入れは休止を許す組を狭めた存在の確認、不足が残る確認で最適性を示せなければ時間切れ、最後の問いと出力に最後に受け入れた確認の編成を使う、注記は最後の編成で判定し直す
- （作成者の仮定）序盤の長さ1時間と応援を受けられる最初の隊の第5隊をドメインの定数にした（ADR 0035）
