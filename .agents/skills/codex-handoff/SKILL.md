# Codex Subagentへ引き継ぐ

現在の作業を続行できる自己完結した引き継ぎ文を作り、CodexのSubagent機能で新しいAgentを
一つ起動する。Shellから別のAgent製品やCodex CLIを起動しない。

## 引き継ぎ文を作る

次の情報だけを簡潔に含める。

- 目的と完了条件
- 現在の状態と完了済みの作業
- 重要な判断、制約、未解決事項
- 続けて読むファイル、Issue、仕様、差分などの参照先
- 実行済みの検証と結果
- 次に行う具体的な作業
- 使用を推奨するSkill

仕様、ADR、Issue、Commit、差分へ既に記録された内容は複製せず、パスまたはURLで参照する。
APIキー、パスワード、トークン、個人情報などの機密情報を除外する。利用者が引き継ぎ先の目的を
指定した場合は、その目的へ要約と次の作業を絞る。

## Subagentを起動する

CodexのSubagent機能が利用できる場合は、引き継ぎ文をTaskとして一つのAgentへ渡す。
Task名は目的を表す短い英小文字の識別子にする。Agentを起動したら、Task名と引き継いだ目的を
利用者へ返し、Main Agent側で同じ作業を重複して進めない。

Subagent機能を利用できない場合は、引き継ぎ文をそのまま利用者へ返し、起動できなかった理由を
一文で示す。引き継ぎのためだけにRepositoryへ新しい文書を保存しない。
